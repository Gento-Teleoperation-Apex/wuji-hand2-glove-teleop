# 2.3.0-test.3 验证记录（预发布）

2026-10-21，修复用户截图中的“扫描到手套，但没有已连接的物理有线接口”。

根因已复现：Ubuntu 的 `ip -j -4 address show` 输出不含 `link_type`，旧代码将所有网卡排除。旧网络规划测试使用人工构造的数据，命名空间测试又替换了整个 `wired()` 判定，因此没有覆盖此错误。此次新增回归先在旧实现下失败（`None != ether`），修复后通过。

- 网络测试 28 项通过（原 24 项 + 4 项实际地址/链路 JSON 合并和接口筛选回归）。
- 在本机仅只读运行修复后的真实网卡识别：识别到物理有线 `eno1`；loopback、CAN、无线接口仍被排除。未修改本机网络，未扫描实体手套。
- 真实 Linux 隔离命名空间测试通过：生产代码读取并合并 `ip` 输出，使用真实 `wired()` 判断；仅将 veth 的 sysfs 物理设备属性替换为测试值。后续 ARP 定位、占用 .200 后选择 .201、双目标 ping、幂等、原 IP/默认网关保留及失败回滚均通过。
- 两个架构的 deb 重新构建并检查载荷、哈希、语法和启动入口；SDK/机械手控制代码未改。

仍为测试版：修复后的实体手套网络准备、ARM64 实机和遥操效果待用户验证。本次不重跑未修改的 ROS/网页/MCAP 功能；MCAP 依赖限制见历史记录。
